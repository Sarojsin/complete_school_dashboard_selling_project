## 2. Dean (Academic Head)

### What Dean Does

The Dean is the academic head overseeing multiple departments. They ensure quality education across all programs and handle strategic planning.

### Core Responsibilities

#### 2.1 Department Oversight
| Task | Description | How It's Done |
|------|-------------|---------------|
| Monitor Departments | Supervise all department activities | Dean views reports from HODs |
| Approve Programs | Authorize new program launches | Dean reviews proposal and approves |
| Set Academic Policies | Define rules for all departments | Dean creates policies, HODs implement |
| Quality Assurance | Ensure education quality | Dean conducts reviews, audits |

#### 2.2 Faculty Management
| Task | Description | How It's Done |
|------|-------------|---------------|
| Approve Hiring | Authorize new faculty positions | Dean reviews HOD requests |
| Evaluate Performance | Assess department heads | Dean reviews performance metrics |
| Promote Faculty | Recommend promotions | Dean forwards to management |

#### 2.3 Academic Planning
| Task | Description | How It's Done |
|------|-------------|---------------|
| Curriculum Review | Evaluate course structures | Dean leads curriculum committee |
| Set Standards | Define academic benchmarks | Dean establishes KPIs |
| Handle Appeals | Resolve academic disputes | Dean hears student/faculty appeals |

#### 2.4 Timetable Coordination
| Task | Description | How It's Done |
|------|-------------|---------------|
| Inter-department Coordination | Resolve scheduling conflicts | Dean mediates between HODs |
| Approve Calendar | Finalize academic calendar | Dean approves term dates, exams |

## 3. HOD (Head of Department)

### What HOD Does

The HOD manages a specific department (e.g., Computer Science, Physics). They are responsible for all academic and administrative activities within their department.

### Core Responsibilities

#### 3.1 Department Administration
| Task | Description | How It's Done |
|------|-------------|---------------|
| Manage Faculty | Lead department teachers | HOD assigns courses, monitors performance |
| Department Budget | Plan department expenses | HOD submits budget to Dean |
| Resource Allocation | Distribute department resources | HOD assigns labs, equipment |

#### 3.2 Faculty Management
| Task | Description | How It's Done |
|------|-------------|---------------|
| Assign Courses | Allocate courses to faculty | HOD maps faculty to courses |
| Course Load Distribution | Balance teaching work | HOD ensures fair distribution |
| Faculty Leave | Approve faculty leave | HOD reviews and approves |
| Performance Review | Evaluate faculty | HOD conducts appraisals |

#### 3.3 Student Management
| Task | Description | How It's Done |
|------|-------------|---------------|
| Department Students | Oversee department students | HOD monitors progress |
| Academic Advising | Guide student course selection | HOD assigns advisors |
| Handle Complaints | Resolve student issues | HOD addresses grievances |

#### 3.4 Curriculum Development
| Task | Description | How It's Done |
|------|-------------|---------------|
| Update Syllabus | Modify course content | HOD leads syllabus revision |
| Add New Courses | Propose elective courses | HOD submits to Dean |
| Textbooks | Select course textbooks | HOD recommends books |

#### 3.5 Lab & Resources
| Task | Description | How It's Done |
|------|-------------|---------------|
| Lab Management | Oversee department labs | HOD assigns lab incharges |
| Equipment | Procure lab equipment | HOD initiates purchase requests |
| Software | License software requirements | HOD submits requirements |

```
College/University
├── Undergraduate (Bachelor's)
│   ├── BSc (3-4 years)

│
├── Postgraduate (Master's)
│   ├── MSc (2 years)
│   ├── MA (2 years)
│   ├── MCom (2 years)
│   ├── MBA (2 years)
│   ├── ME/MTech (2 years)
│   └── Professional Masters
│
├── Doctoral (PhD)
│   ├── Full-time PhD
│   ├── Part-time PhD
│   └── Integrated MS-PhD
│
└── Diploma/Certificate
    ├── PG Diploma
    └── Certificate Courses
```

### Semester System

```
Academic Year
├── Fall Semester (August - December)
│   ├── Course Registration
│   ├── Mid-term Exams
│   ├── End-term Exams
│   └── Grade Publication
│
├── Spring Semester (January - May)
│   ├── Course Registration
│   ├── Mid-term Exams
│   ├── End-term Exams
│   └── Grade Publication
│
└── Summer Term (Optional)
    ├── Short Courses
    └── Internships
```

## 16. Key Differences: School vs College

| Aspect | School | College |
|--------|--------|---------|
| **Structure** | Classes 1-12 | Programs (BSc, MSc, PhD) |
| **Terms** | Terms/Annual | Semesters |
| **Students** | Fixed class | Variable credits |
| **Teachers** | Class Teacher | Faculty/Professor |
| **Assessment** | Marks/Percentage | GPA/CGPA |
| **Roles** | Authority | Dean, HOD, Registrar |
| **Exams** | Annual/Unit Tests | Mid-sem, End-sem |
| **Research** | Not applicable | Major component |
| **Placements** | Not applicable | Career services |
| **Hostel** | Optional | Common for many |
| **Curriculum** | Fixed | Some elective choices |
